# S09 原提示词资源和加载

原 Java 中英文 18 个提示词资源迁入 backend/app/resources/prompts，另加 2 个简单问答模板。分类、SQL、工作流、对比、上下文策略、步骤压缩、历史压缩和最终总结的原结构及约束保留；参数名对齐当前受控工具。原 db-genius 只读。AGENTS.md 只新增 prompts 目录条目，未记录实现细节。

prompts.py 使用 importlib.resources，zh-CN/zh_CN 用原 zh_CN 模板，其余语言用原英文模板并明确要求输出语言。占位符仅替换原模板一次，JSON 花括号和用户文本不会被二次插值；===USER=== 最多一个。分类将历史和问题作为独立消息发送。

system_prompt/classification_prompt 接口保持。工具对应 getDatabaseSchema(db_id)、executeSql(db_id,statement)、readFile/readImage(file_id)、compareDatabases(pre_id,test_id)、readToolOutput(artifact_id,offset,length)、doTerminate(reason)。授权仍由工具和数据库服务执行。

当前 S09 SQL 图、历史压缩、运行内压缩、制品分页和重复调用限制已接通；workflow 和 db_compare 图仍明确返回阶段未实现错误，资源保留后续目标，不能当作对应能力已通过。后续实现继续复用这些原提示词。
